# Linux Administration & Security Labs

Hands-on Linux administration and security labs completed as part of my
**Linux & Cloud Security / Segurança em Infraestruturas Cloud** training.

This repository documents my progression from basic Ubuntu Server administration
and remote access through users and permissions, web-service deployment,
server security, hardening, monitoring, maintenance, and troubleshooting.

The goal of the repository is to show practical Linux systems administration
work rather than only theoretical coursework.
