# 01 — Linux Environment Setup

Hands-on Linux lab focused on preparing and validating the Ubuntu environment used throughout the Linux Administration & Security labs.

## Objective

Prepare a working Linux environment for the training module, confirm basic system and network functionality, and establish the Git/GitHub workflow used to document the following activities.

---

## Areas Practiced

- Linux command-line navigation
- system identification
- hostname and user checks
- IP and network-interface inspection
- connectivity testing
- package management
- Git installation and configuration
- SSH
- GitHub authentication
- repository cloning and synchronization
- technical documentation

---

## Environment

- **Operating System:** Ubuntu Linux
- **Interface:** Linux CLI
- **Version Control:** Git
- **Repository Hosting:** GitHub
- **Remote / Secure Access:** SSH
- **Package Management:** APT

---
